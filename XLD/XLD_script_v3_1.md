### ⚙️ 2. 脚本控制逻辑全解析
这份代码将冷凝到循环的过程分为了6个主要阶段，以下是每个阶段的工作原理：

#### 第一阶段：条件检查与预备 (State 400 - 404)
*   **State 400**：等待冷盘达到目标温度（T2<4K, T5<5K）。
*   **State 401**：关闭所有关键阀门（V15, V17等），切断涡轮分子泵（Turbo1）。然后开启V9, V7, V6, V5和压缩机（Compressor），建立通过冷阱（Trap）的内部小循环，净化并预冷管路。
*   **State 402 - 404**：启动前级泵 Scroll1（面板上的S1），随后打开V10和V2，最后打开主闸阀V1（Gate Valve），关闭V2。此时记录当前储气罐压力 `p5`（面板显示为735.70 mbar）并存入变量 `var3`。正式进入冷凝阶段。

#### 第二阶段：高压冷凝阶段 (State 410 - 415)
由于当前的 `P5 = 735.70 mbar`（远大于250），系统进入后将首先在此阶段运行。
*   **压力控制机制**：通过交替开关 **V12** 和 **V10** 来将混合气“脉冲式”注入系统。
    *   当冷凝压力 `P4 < 600 mbar` 时（State 411），打开V12，从储气罐放气进入系统。
    *   当冷凝压力 `P4 > 900 mbar` 时（State 414），关闭V12，防止系统内压力过高，给系统时间吸收和冷凝气体。
*   **安全与防呆机制**：State 412 中有一个计时器，如果 V12 开启超过 180秒 且 P5 依然大于 300 mbar，系统会报错提示 `Needle valve set too tight!`（针阀调得太紧了，导致进气太慢）。
*   **热开关控制**：如果在高压冷凝期间，罐压 `P5` 下降超过 80 mbar，说明已经有相当一部分气体进入系统冷凝，此时会关闭 STILL 和 MXC 的热开关（`OFF hs-still`, `OFF hs-mc`），让它们靠冷凝的液氦进一步降温。

#### 第三阶段：低压冷凝阶段 (State 420 - 423)
当储气罐压力 `P5` 降至 250 mbar 以下，且大于 50 mbar 时进入此阶段。
*   **控制逻辑**：不再使用V12，而是改用 **V11** 进行进气。
*   同样维持 P4 在 600 ~ 900 mbar 之间震荡（State 421/422）。
*   新增了 **State 423（极速冷凝状态）**：如果此时 `P5 < 1 mbar`，说明气体被非常快速地吸入，系统会直接跳转到抽空储气罐阶段。

#### 第四阶段：抽空储气罐 (State 430 - 431)
当 `P5 < 50 mbar` 时，说明大部分气体已经冷凝。
*   系统将长开 **V11** 300秒，通过泵组将储气罐（Tank）内剩余的混合气彻底抽入制冷机循环系统中。
*   之后关闭V11，准备进入连续循环。

#### 第五阶段：启动连续循环 (State 440 - 443)
此时冷凝基本完成，系统要切换到闭环稀释制冷循环。
*   **State 440**：关闭压缩机。
*   **State 441 - 442**：检测返回端压力 `P3`。当 `P3 < 1000 mbar` 且 `P3 < P4` 时，打开 **V4** 和 **V10**，正式连通循环气路（此时He3通过V4返回系统，不再回Tank）。
*   **State 443**：当系统前端压力被抽至相对低压（`P3 < 700 mbar`）时，启动核心的涡轮分子泵 **Turbo1 (T1)**。涡轮泵的启动标志着高通量稀释循环的开始。
*   等待 1200 秒（20分钟）让系统流动稳定。

#### 第六阶段：启动蒸馏室加热 (State 500)
*   打开 STILL 的加热器（`ON Pstill`）。STILL加热是为了促进He3的蒸发，维持高循环率，从而让混合室（MXC）温度进一步下降至mK级别。
*   脚本执行完毕 (`STOP`, `END`)。
